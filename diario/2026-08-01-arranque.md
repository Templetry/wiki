## Qué se hizo

1. **Análisis de viabilidad**: el hueco es el punto medio entre GitHub Templates (copia tonta) y Backstage (portal enterprise pesadísimo) — un gestor personal/ligero de plantillas con creación de repos.

3. **Cambio de requisito clave**: multi-forge (RF9) — el repo destino se crea en cualquier alojador git, no solo GitHub → ADR-0009.
4. **Decisión motor propio vs Copier**: verificado el estado del arte actual; se construye propio → ADR-0001.
5. **Nombre**: ~70 candidatos verificados en 6 tandas (GitHub + npm + colisiones de producto). Ganador: **Templetry** → ADR-0008. Finalistas con pleno de disponibilidad, como plan B: Repojig, Forgehand.
6. **Infraestructura**: instalado GitHub CLI; creado este repo wiki con el estudio troceado en ADRs.
