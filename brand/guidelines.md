# Templetry brand guidelines — v1

**Status:** normative for every Templetry surface (desktop app, org profile, docs, future web).

## Story

*Templetry* comes from **templet** — the original spelling of "template" and a real loom tool: the piece that keeps the cloth's shape while it is woven. The brand world is the **weaving workshop**: warp threads (structure the engine guarantees), the brass shuttle (the tool moving fast), linen (the material). Never rockets, never lightning bolts, never generic "dev tool" glyphs.

## Logo

`brand/logo.svg` — five brass warp threads crossed by a linen weft bar, woven over-under. Clear-space: one thread-width around. Never recolor, never add effects. The mark works at 16 px (favicon) and up.

## Palette — "Ink & Brass"

| Token | Hex | Role |
|---|---|---|
| Ink | `#15171e` | Primary background |
| Ink 2 | `#1b1e27` | Raised surfaces, cards |
| Thread | `#2c303d` | Borders, dividers (stitched/dashed when structural) |
| Linen | `#eae7de` | Primary text, the weft |
| Linen dim | `#969aa8` | Secondary text |
| **Brass** | `#d9a441` | THE accent: actions, focus, active states, the shuttle |
| Brass deep | `#b5852c` | Brass hover/borders |
| Loom green | `#a4d9a9` | Success output only |
| Warning red | `#ff9090` | Errors only |

Rule: **brass is spent, not sprayed** — one accent, on the thing that matters. Light-mode variant (docs/print): Linen `#f2efe6` background, Ink text, same brass.

## Typography

- **UI / headings:** Segoe UI / system-ui, weight 650 for headings, sentence case always.
- **Data voice:** Consolas / monospace — paths, codes, plan output, metadata. Only data.
- Section labels: 11.5 px uppercase, 1.2 px letter-spacing, brass, over a dashed "stitch" divider.

## Signature motif

The **warp**: thin vertical brass threads (10% opacity as background texture behind the wordmark) and **stitched dashed dividers**. This motif is the identity — use it before inventing new decoration.

## Voice

Plain verbs, sentence case, no filler. Buttons say exactly what happens ("Create repo & project"). Errors state what went wrong and how to fix it — no apologies, no vagueness. Empty states are invitations to act.
